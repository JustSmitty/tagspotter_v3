# Tag Spotter

Every road trip is a collection challenge. Mark plates as you spot them, unlock state trivia, and
earn bonus points for how far each sighting is from where you are.

All 50 states plus Washington, D.C.

## About the app

- Works offline. Your collection is stored on your own device.
- Location is used only when you mark a plate as found, to work out a distance bonus. It is never
  stored and never leaves the phone.
- No account, no ads, no tracking.

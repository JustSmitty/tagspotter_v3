# Store Assets Checklist

## Required before submission

- Android phone screenshots in `store-assets/google-play/phone`
- iPhone screenshots in `store-assets/app-store/iphone`
- 1024x1024 marketing icon review signoff
- Final support URL
- Final privacy policy URL

## Recommended

- Feature graphic for Google Play
- App Preview or short promo video
- Updated launch notes for the release

## Notes

- Capture screenshots from release builds, not dev builds.
- Use the same app name and point totals style across all screenshots.
- Re-check the permission copy on the screen flow used for location.

Baseline at audit time: lint clean, 75/75 specs pass, prod build 1.29 MB initial / 15 MB `www/`.
The core architecture (store → command service → view-model service, OnPush + signals, strict TS)
was found sound. Everything below is the layer around it. Phasing lives in
`docs/remediation-plan.md`; enforcement lives in `.agents/evals/guardrails.json`.

## Product & identity

- **F-01** Golf metaphor fights the Americana design system — ~28 strings, 9 files. → dec-0008
- **F-02** Onboarding claims an "AI Caddie". There is no AI in the app. False + store risk.
- **F-03** README says MapLibre GL (line 48) and inline SVG (line 87). Both were true, at different
  times. → dec-0004
- **F-04** No un-spot. A mis-tap is permanent; only escape is a full progress reset.
- **F-05** Trivia mode commits a plate with no confirmation dialog (classic mode has one).
- **F-06** `GameCommandService.recordFoundState` awaits geolocation inside the mutation queue, so
  `isBusy` disables the entire UI for up to the 10 s timeout, with no spinner.
- **F-07** "Miles" are device→state-centroid distance, summed. Not travel. Copy calls it "miles
  traveled" and "odometer".
- **F-08** `/summary` has no nav entry; `openSummary()` in home.page.ts is never bound. Share and
  trip stats are invisible below 51/51.
- **F-09** `summary.page.ts` `viewMap()` navigates to `/dashboard`.
- **F-10** No dark mode; `color-scheme: light` hardcoded. Worst gap for a night-time car app.
- **F-11** Rotating daily challenges award nothing.
- **F-12** Achievements unlock with no toast, animation or haptic.
- **F-13** Distance caps at 5 pts; a perfect hard trivia round is 9. The road-trip half of the game
  is ~10% of score.
- **F-14** Trip history is archived (max 10) but only rendered as a flat list.

## Correctness

- **F-15** `home-workflow.recordState` reads `gameMode()` after an await; toggling mid-dialog
  desyncs the stored mode from the quiz that runs.
- **F-16** `AppComponent.isRouteActive` uses `url.includes(route)`.
- **F-17** `RoadAtlasComponent` uses an `effect` that writes a signal purely to re-sync a stored
  object against the store. Should hold an ID and derive via `computed`.
- **F-18** Quiz hardcodes 3 questions; the `medium` tier has exactly 3 topics with no guard, and the
  accuracy denominator is a literal `QUIZ_QUESTION_COUNT`.
- **F-19** `persistSnapshot` runs before `setSnapshot`, so a storage failure discards the spot the
  player just made and the banner does not say which action failed.

## Security & privacy

- **F-20** Save "encryption": hardcoded password + hardcoded salt + 1000 PBKDF2 iterations, all in
  the shipped bundle. → dec-0005
- **F-21** CSP still allows `script-src 'unsafe-eval'` for a removed MapLibre dependency. → con-0002
- **F-22** `allowBackup="true"` with no `dataExtractionRules` for API 31+.

Positives worth preserving: coarse-location default (dec-0007) and the honest privacy footer.

## Performance

- **F-23** 8.4 MB of raw Inkscape SVG flags. Pennsylvania is 775 KB, rendered at 56×56 px. Four
  parse simultaneously in a hard flag question.
- **F-24** 3.6 MB of ionicons SVGs copied into `www/` and never used — every icon goes through
  `addIcons()`.
- **F-25** Deprecated `@angular-devkit/build-angular:browser` (webpack) builder.
- **F-26** Zone.js retained though every component is OnPush + signals with no manual
  `markForCheck`.
- **F-27** `PreloadAllModules` eagerly fetches every lazy route right after boot.
- **F-28** `states.json` (37 KB) statically imported into `main.js` via `resolveJsonModule`.

F-23 + F-24 together take `www/` from 15 MB to ~2.5 MB.

## Accessibility

- **F-29** `maximum-scale=1.0, user-scalable=no` blocks pinch zoom. WCAG 1.4.4 failure.
- **F-30** `.footer-note` at `rgba(0,0,0,0.3)` on cream ≈ 2.5:1; atlas placeholder at 0.4 likewise.
- **F-31** `prefers-reduced-motion` handled only in `road-atlas.component.scss`; the five animations
  in `global.scss` (including the pulsing neon sign) are unguarded.
- **F-32** 51 `<path role="button" tabindex="0">` sit above a plate grid that does the same job.
- **F-33** Mode switch announces "Toggle trivia mode" while displaying LAYUP/ATTACK. Resolves with
  F-01.

## Build & process

- **F-34** `minifyEnabled false` on the release APK — no R8.
- **F-35** No CI at all.
- **F-36** Karma defaults to non-headless `Chrome`, `singleRun: false`.
- **F-37** `home-workflow.service.ts` (270 lines, the most complex file) and
  `game-command.service.ts` (all scoring math) have zero specs, while trivial components have full
  ones.
- **F-38** Legacy `.eslintrc.json` under ESLint 9.
- **F-39** `target: es2022` but `lib: ["es2018","dom"]`; `useDefineForClassFields: false`.
- **F-40** `versionCode` / `versionName` / `package.json` version hand-synced.
- **F-41** Angular CLI analytics UUID committed to `angular.json`.

## Closed — 2026-08-24

All 41 findings above are closed, across the five phases in `docs/remediation-plan.md`, landing in
`1a0b5b2`. Enforcement moved into `.agents/evals/guardrails.json`: 22 guardrails, every one at
baseline 0, so each closed finding is now a regression test rather than something to remember.

Two were closed by **deciding not to do them**, which is the part a future reader needs:

- **F-28** (`states.json` statically imported) — declined. Moving 37 KB raw / ~12 KB gzipped out of
  the bundle adds a failure mode to the seed-data path that everything else depends on: if the fetch
  fails there are no states at all, and guarding against that means bundling a fallback, which is
  where we started. In a Capacitor shell both paths are a local file read. Revisit only if
  `states.json` grows by an order of magnitude.
- **F-07's honest version** — the copy rename to Spotting Range shipped, but *real* trip-distance
  tracking did not. It needs continuous location sampling, which collides with
  `dec-0007-coarse-location-default` and the privacy posture the store listing already promises.
  That is a product decision with a permissions cost, not a backlog item to pick up quietly.

Findings raised *after* this audit are their own records: `f-042-contrast-debt`,
`f-043-nav-icons-were-black`, `f-044-store-readiness`, `f-045-resolver-substring-keyword-collisions`,
`f-046-block-form-claims-parse-as-a-list`, `f-047-guardrails-do-not-cover-the-instruction-layer`.
F-44 is store readiness — the work neither store will accept the app without — and it has no entry in
`docs/remediation-plan.md`, which stops at Phase 5; it lives as `phase: 6` in the guardrails file.

Flipped `open` → `resolved` because this register was still being retrieved as a live backlog five
phases after it was finished, and `open` is authoritative for the claims check while `resolved` is
not. An agent reading it cold would have re-opened settled work.
